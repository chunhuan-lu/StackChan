- 阅读代码时的发现，以及它们对设计的影响：
  - `BreathModifier` 每 600 ms 按增量移动五官，而且不检查 avatar 锁 → 表情动画的位置改用相对偏移，否则脸会慢慢漂移。
  - `BlinkModifier` 会恢复它之前保存的眼皮位置 → 播放动画或处于睡姿时，锁住 avatar。
  - LED 0 是对话状态指示灯，LED 0–5 和 6–11 分别是左、右灯条 → 心情灯直接写 LED 1–5 和 7–11，每秒最多 10 次，只在颜色变化时写入。
  - `removeModifier()` 会在持有显示锁的情况下立即销毁对象 → 由析构函数恢复表情、背光和灯光。
    在电池省电路径上（先 `SetEmotion("sleepy")` 再移除调度器），保留困倦的表情。
  - 头顶触摸本来就会上报 Press / Release / SwipeForward / SwipeBackward 四种事件；`HeadPetModifier` 只处理"撸"，
    所以新增的轻拍和长按不会和它冲突。
  - 小智的 OTA 检查会把系统时钟按时区偏移拨动，之后再由 SNTP 校正回来；默认时区是 `GMT0`
    → 作息只在 SNTP 同步后才生效，fork 的默认时区改为 `CST-8`。
  - LTR-553 环境光传感器原本没有驱动 → 写了一个只读环境光的最小驱动（寄存器已对照数据手册核对）。
