# REQ-002 待机行为（第一批）

[English](REQ-002-idle-behaviour.md) | **中文**

状态：已在 `feat/idle-behavior` 分支实现（从 `feat/wake-word` 拉出），编译通过，**尚未真机验证** · 对应 backlog：B-011

## 目标

让 AI Agent 的待机状态显得有生命力，而不只是"随机转头"，同时保持安静。

## 维护者的决定（2026-10-20）

- 第一批全部实现，先用着体验。
- **静音**：待机时完全不发出声音。
- 当地时间 **08:00–23:00** 清醒。
- **安静**：头少动，大部分"看"由屏幕上的眼睛完成。

## 设计

### 内心状态（`IdleMood`，每次对话后调度器重建也能延续）

| 数值 | 范围 | 变化方式 |
|---|---|---|
| 精力 | 0–1 | 跟随时间（上午 0.9，午后低谷 0.5，22 点后 0.35） |
| 无聊 | 0–1 | 没人互动时每 45 分钟 +1；触摸、拿起、对话会降低它；睡觉时逐渐回落 |
| 心情 | 0–1 | 撸毛、对话会提升，连续轻拍、摇晃会降低；约 30 分钟回到 0.5 |
| 亲密度 | 0–1 | 随撸毛缓慢增长（只在运行期间保存，暂不持久化） |
| 转头配额 | 0–上限 | 舵机配额，按 `SC_IDLE_HEAD_MOVES_PER_HOUR` × 活跃度倍数补充 |

### 行为调度器（`IdleDirectorModifier`）

在 `StackChanAvatarDisplay` 的待机槽位上取代官方的 `IdleMotionModifier` 和 `IdleExpressionModifier`
（仅在 `CONFIG_SC_IDLE_DIRECTOR=y` 时生效）。每隔几秒，按内心状态加权随机挑选行为，带冷却时间，不会立刻重复同一个行为。

| 方面 | 行为 |
|---|---|
| 眼神瞟动 | 约每 6–15 秒一次（越无聊越频繁），只动屏幕 |
| 主动行为 | 活跃度 2 时约每 45–120 秒一次：转头张望（用舵机，受配额限制）、打哈欠（累的时候）、斜眼看灯、叹气（无聊时）、追虫子（无聊时，眼睛追着一个小点）、打喷嚏或打嗝（很少）、无声哼歌（开心时）、午后打瞌睡、只用眼睛环顾四周，或者什么都不做 |
| 作息 | 08:00–23:00 以外：打瞌睡然后入睡；早上 8 点伸懒腰起床（要等房间亮了才起） |
| 天黑 | 环境光低于 `SC_IDLE_DARK_LUX` 持续 1 分钟就入睡；高于 `SC_IDLE_BRIGHT_LUX` 持续 5 秒就醒来（如果是夜里，只会不高兴地睁一只眼瞄一下，然后继续睡） |
| 睡姿 | 眼睛几乎闭上，偶尔冒"Zzz"气泡，很少会说梦话（"..."）；低头；背光调到 `SC_IDLE_SLEEP_BACKLIGHT`；心情灯熄灭 |
| 无聊升级 | 越无聊，越容易环顾四周、追虫子；无聊值 ≥ 0.92 时会小睡 10 分钟 |
| 摸头 | 撸毛（沿用原有的爱心反应）后有余韵：满足地眯眼，灯光变成粉色心跳；快速轻拍 3 下：生气；拍 6 下：头晕；长按 2.5 秒：被哄着小睡 10 分钟；睡着时摸它：睁眼瞄一下（夜里或天黑时），或者醒来（小睡时） |
| 被拿起、放下 | 被拿起：吓得睁大眼睛，冒"?!"，被拿着时四处张望；放下：松一口气（流汗、开心） |
| 倾斜超过 22° | 疑惑加流汗，直到放平为止 |
| 心情灯 | 用 LED 1–5 和 7–11（LED 0 和 6 留给状态指示灯）；颜色反映心情（蓝色不高兴 / 青色平静 / 琥珀色开心），亮度反映精力，缓慢呼吸；单通道最大值 `SC_IDLE_LED_MAX` |

### 时间

- 作息只在本次开机 SNTP 同步完成后才生效（`Hal::isTimeSynced()`），因为在那之前，小智的 OTA 检查会把系统时钟按时区偏移拨动过。
- 默认时区 `SC_DEFAULT_TIMEZONE` = `CST-8`（官方默认是 `GMT0`）；在「设置 → 系统」里选择的时区优先。

## 与原计划的差异

- **倾斜时"头往反方向保持水平"推迟实现**：IMU 装在头上，它的坐标轴和正负方向与俯仰舵机的对应关系还不清楚。
  第一批只做表情反应。调度器每分钟会在日志里输出一次重力向量（`imu g=(...)`），第一次真机测试时就能标定坐标轴。

## 已知限制

- 用电池时，官方的省电计时器在待机 5 分钟后仍会接管（显示"sleepy"和 Zzz），到了待机关机时间（默认 10 分钟）就会关机。
  这个调度器主要面向 USB 供电的场景。
- 照度和 IMU 的阈值都是初步估计，需要在真机上调整（照度每 5 分钟记一次日志）。
- 内心状态在重启后不会保留。

## 验收标准（真机，USB 供电）

1. 待机时能看到眼神瞟动和偶尔的主动行为；转头很少（日志 `behaviour: head-look`，大约每小时不超过 20 次）；全程不发出任何声音。
2. 心情灯在 LED 1–5、7–11 上可见；对话时 LED 0 仍正常显示聆听、说话状态。
3. 遮住环境光传感器（或者关灯）超过 1 分钟 → 打瞌睡入睡；恢复光线 → 醒来。
4. 23:00 到 08:00 之间（SNTP 同步后）处于睡眠状态；摸它会睁一只眼瞄一下；早上 8 点（房间亮着）伸懒腰醒来。
5. 轻拍 3 下 → 生气，6 下 → 头晕；长按 → 小睡；撸两次以上 → 余韵。
6. 被拿起 → 受惊，放下 → 松一口气；倾斜超过 22° → 疑惑、流汗。
7. 任何时候（包括睡觉时）喊唤醒词都能正常开始对话；对话结束后，表情、背光、灯光都恢复正常。
