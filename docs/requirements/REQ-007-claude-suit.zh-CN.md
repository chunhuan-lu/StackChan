# REQ-007 Claude Code 像素小伙伴皮套

[English](REQ-007-claude-suit.md) | **中文**

状态：已在 `feat/claude-suit` 分支实现，2026-10-21 已烧录；转场还没在真机上看过 · 对应 backlog：B-023

## 目标

Claude Code 干活时，机器人要变成「Claude 机器人」的样子，从普通的脸进出时有好玩的转场。维护者从 4 个设计方向里选了 C（橙色
像素小伙伴，参考 Claude Code 终端里的像素小家伙）。过程中提出的要求：

- 干活时满头大汗；
- 进场：StackChan 被套上一套 Claude 皮套；
- 出场：小伙伴用自己的手拉开拉链，手连着长手臂（不要像一个方块飞出去），手和手臂带轮廓，跟身体区分开；
- 转场时舵机配合动头，可以在设置面板里开关和调速；
- 要正的橙色：品牌陶土色（#D97757）在 CoreS3 的 LCD 上发灰，所以颜色做成设置，有陶土、橙色（#F2711C，默认）和亮橙（#FF5F00）
  三种，在真机上对比。

设计画布（私有）：StackChan Claude 表情，画板「C 像素小伙伴」「穿上 Claude 皮套」「脱下 Claude 皮套」。

## 什么时候穿

- **穿上**：有联动的会话在干活或等你，机器人醒着、不是夜里，并且 `claude_suit`、`claude`、`faces` 三个设置都开着。刚聊完天
  （导演重新创建）时直接穿回去，不播转场。
- **脱下**：最后一次有会话在干活或等你之后过了 `suit_off_min` 分钟（默认 2），这样两次提问之间不会反复换装；到了夜里或者关掉
  某个设置时，立即播出场转场脱下。
- 穿着的时候机器人不会打瞌睡，待机小动作和特殊表情暂停（它们画的是被隐藏的默认五官）。对话照旧用官方的脸。

## 姿态

| 姿态 | 什么时候 | 样子 |
|---|---|---|
| 空闲 | 没有会话在忙、还没脱皮套 | 像素眼，偶尔眨眼、瞟一眼 |
| 思考 | 刚收到任务、子代理在跑、搜网页 | 眼睛往上看，三个点 |
| 干活 | 改文件、跑命令、读代码、测试 | 眼睛往下看，钳子轮流敲，汗往外飞、往下淌 |
| 叫你 | 有会话在等你 | 大眼睛，右钳招手，「!」 |
| 完成 | `done` / `pass`，会话结束后 20 秒内 | 「^ ^」眼，双钳举高，撒彩纸 |
| 失败 | 测试或编译失败 | 「> <」眼，钳子耷拉，一滴汗 |
| 出错 | API 出错 | 「T T」眼，流眼泪 |
| 压缩 | 压缩上下文 | 每只眼里一个方块转圈 |
| 吃撑 | 上下文超过 80% | 一字眼，粉色脸蛋 |

## 转场

| 转场 | 步骤 | 头（舵机） |
|---|---|---|
| 穿上，2.8 秒 | 皮套从上面降下来晃两下，StackChan 抬头张嘴；咚地套上，压扁，冒灰；在里面扭一扭，白眼睛从眼洞往外瞄；眨一下变成像素眼；伸出钳子和腿，亮相 | 落下时点一下头，亮相时抬一下 |
| 脱下，3.6 秒 | 满头大汗的小伙伴；带轮廓的长手臂绕过头顶抓住拉链头往下拉，眼睛跟着看；冒热气；两半皮套掉下去；热得通红、满头汗的 StackChan 甩汗、睁眼、微笑、呼一口气 | 冒热气时往后一仰，甩汗时左右摇（偏航 ±15°） |

俯仰保持在 13–30°（限制 5–85°）。速度：动作用 `suit_head_spd`，回位用它的三分之一。

## 设置（REQ-006 面板和语音）

| 键 | 面板标签 | 范围 | 默认值（Kconfig） |
|---|---|---|---|
| `claude_suit` | Pixel buddy suit | 开 / 关 | `SC_CLAUDE_SUIT` y |
| `suit_color` | Suit colour | Clay / Orange / Bright | `SC_CLAUDE_SUIT_COLOR` 1（橙色） |
| `suit_off_min` | Suit off after | 1–30 分钟 | `SC_CLAUDE_SUIT_OFF_MINUTES` 2 |
| `suit_head` | Head moves along | 开 / 关 | `SC_CLAUDE_SUIT_HEAD` y |
| `suit_head_spd` | Head speed | 100–1000（50） | `SC_CLAUDE_SUIT_HEAD_SPEED` 600 |

都需要 `SC_IDLE_DIRECTOR` + `SC_USB_LINK`。

## 实现

- `main/stackchan/sc/pixel_buddy.*`：小伙伴和两个转场，用大约 50 个普通 LVGL 矩形（StackChan 自己的脸另有三条白线）画在头像
  面板的一个图层上，位于默认五官之上、对话气泡之下。每帧（40 毫秒）按转场里的时间设置位置和大小，只改有变化的对象。眼洞会裁剪
  从里面往外瞄的眼睛；长手臂由沿身体侧面的上臂和通向手的前臂组成，按手的位置重新计算。转场会发出头部动作提示（点头、抬头、
  后仰、摇头）。
- `main/stackchan/sc/idle_director.*`：什么时候穿、按 Claude 会话状态和事件选姿态（优先级和表情一致），把动作提示转成舵机动作
  （`suit_head`、`suit_head_spd`）。
- 关掉皮套（`claude_suit`）时照旧用 REQ-005 的 Claude 表情。

## 验收标准（真机）

1. 在联动的会话里提问：穿皮套转场播一次，带点头和抬头。
2. 干活时冒汗、钳子敲；叫你 / 完成 / 失败 / 出错 / 压缩的姿态按表出现。
3. 会话停下 2 分钟后：脱皮套转场，有手臂、拉链、热气、掉落的两半、后仰和摇头，最后回到温和微笑。
4. 两次提问之间不会反复换装；中间聊一次天，皮套直接回来，不播转场。
5. 关掉 `suit_head`：转场时头不动；`suit_head_spd` 改变动作快慢。
6. 反复穿脱多次不崩溃、不残留对象（堆内存日志稳定）。
