# REQ-005 更生动的表情

[English](REQ-005-faces.md) | **中文**

状态：已在 `feat/claude-link` 分支实现，**尚未真机验证** · 对应 backlog：B-020

## 目标

待机时的脸显得无聊、没精神：两个小圆点加一条 90×6 像素的横线。维护者在预览页（"StackChan 表情候选"，按真实的 320×240
尺寸绘制）里选了全部 16 个表情，要求都集成进去。变化不要太频繁：大部分时间是一张友好的基础脸，偶尔换一个特殊表情。

## 表情怎么画

官方皮肤把眼睛画成白色圆点加一块会滑动的黑色眼皮，嘴是圆角矩形；6 种情绪只改变眼皮位置和眼睛角度。新增的 `FaceArt`
（`main/stackchan/sc/face_art.*`）用 LVGL 对象画矢量表情（圆、圆环、折线、裁剪出来的半圆；星星和水滴是运行时生成、
放在 PSRAM 里的小 ARGB 位图），画在头像面板里的一个图层上：位于眼睛和嘴之上、对话气泡之下，不接收点击。保留圆眼睛的表情
（温和微笑、闪亮大眼、好奇、偷瞄、专注干活、思考中，以及眨眼时睁着的那只）把眨眼和看方向交给原有的修饰器，只加上跟着
眼睛移动的高光；其他表情隐藏默认眼睛，自己画。显示表情期间，默认的嘴总是被替换掉。

## 表情和出现时机

| 表情 | 什么时候 |
|---|---|
| 温和微笑（带高光的圆眼睛、微笑） | AI Agent 待机且醒着时的基础脸 |
| 闪亮大眼、开心弯眼、害羞脸红、好奇、眨眼、哼歌、偷瞄 | 每 4–10 分钟按心情（精力、心情、亲密度、无聊）挑一个，显示 5–8 秒；偷瞄和哼歌也取代了原来的斜眼看灯和无声哼歌；害羞脸红是撸毛后的余韵 |
| 吃撑了（一字眼、鼓腮帮） | 偶尔出现的表情之一；Claude Code 某个会话的上下文超过 80% 时优先出现 |
| 专注干活（眼睛往下看、坚定的眉毛） | Claude Code 会话在干活（改文件、跑命令、读代码、测试） |
| 思考中（眼睛往上看、"…"气泡） | 刚收到任务，或者子代理在跑 |
| 好奇 | 会话在搜网页 |
| 叫你（圆环眼、"!"） | 有会话在等你；不受最短显示时间限制 |
| 完成啦（金色星星眼、张嘴笑） | `done` / `pass` 事件，以及会话完成后的 20 秒 |
| 失败了（> <、锯齿嘴、汗滴） | 测试或编译失败 |
| 出错哭哭（T T 加眼泪） | API 出错，持续 60 秒 |
| 转晕了（旋转的螺旋眼） | 压缩上下文 |

规则：
- 每个表情至少保持 3 秒（Claude Code 快速切换工具时不会闪烁），"叫你"除外。
- 睡觉时、做反应时（被拿起、拍头、摇晃、醒来）、播放会动嘴的动画时（打哈欠、打喷嚏等）、以及情绪覆盖期间，都不显示表情；
  只动眼睛的瞟动可以在温和微笑上继续进行。
- 夜里（23:00–08:00）Claude Code 只改变灯，和之前一样。
- 对话时使用官方的脸（会说话的嘴）；待机行为被销毁时会清掉自己的表情。

## 协议（REQ-003 v1.1）

每个会话的 `act`、`ctx` 和 `pass` 事件驱动 Claude 相关表情；详见 REQ-003。

## 已知限制

- 头不能左右歪（没有滚转舵机），所以"好奇"没有歪头，靠一大一小的眼睛表达。
- 隐藏默认眼睛的表情画在固定位置（这些表情期间没有眼神瞟动）。

## 验收标准（真机）

1. 醒着待机时显示温和微笑；仍然会眨眼和瞟动，高光跟着眼睛走。
2. 大约每 4–10 分钟出现一个特殊表情，几秒后回到温和微笑。
3. 接入 Claude Code 会话后：专注干活 / 思考中 / 叫你 / 完成啦 / 失败了 / 出错哭哭 / 转晕了按上表出现；切换工具时不闪烁。
4. 点屏幕、拿起、拍头和对话都和之前一样；对话结束后回到温和微笑。
5. 睡姿和睡眠亮度（REQ-004）不变。
